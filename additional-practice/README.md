## Option #4: Add a 2nd Route and Implement Another Gemini Service

Gemini provides many helpful resources to help you dig deeper into it's power. Pick one of these links to get inspired and add more Gemini features to your Flask app.

- [Welcome to the Gemini API Cookbook](https://github.com/google-gemini/cookbook/tree/main) - This cookbook provides a structured learning path for using the Gemini API, focusing on hands-on tutorials and practical examples. You'll find Demos of End-to-End Applications and Practical Use Case Examples.

- [Gemini API Quickstart - Python](https://github.com/google-gemini/gemini-api-quickstart) - This repository contains a simple Python Flask App running with the Google AI Gemini API, designed to get you started building with Gemini's multi-modal capabilities. The app comes with a basic UI and a Flask backend similar to the one you built in this module.

- [Image Generation With Gemini (NOTE - Not included with the Gemini free tier)](https://ai.google.dev/gemini-api/docs/image-generation) - If you already have a paid Gemini account or want to experiment with the image generation capabilities.
